# WE FOR EARTH – Tree Pledge & Plantation Tracker

A simple, free, open-source web prototype where youth pledge a tree, record it, and track progress.

By Priyanka Chakraborty, founder of SAVE & PLANT TREES! (started 2020). Blog: https://save-trees-plant-trees.blogspot.com

## Problem
Many plantation drives are one-time events. Students and communities have no easy way to record the saplings they plant or follow up on them.

## Solution
Users add a tree (species, place, status). A dashboard shows trees pledged, trees planted and people taking part.

## Features
- Tree pledge form with input checks
- Plantation log with date and status (Pledged / Planted)
- Live progress counters
- Works on phones and computers, no installation

## Tech stack
HTML, CSS and JavaScript. Data is saved in the browser (localStorage) in this prototype.

## How to run
1. Download this repository (Code > Download ZIP) and unzip it.
2. Open `index.html` in any browser.

Or use the live demo (if GitHub Pages is enabled): see the repository's About section.
